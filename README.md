# 半額ハンター 最小構成

## 起動方法
1. `index.html`、`style.css`、`script.js`を同じフォルダに置きます。
2. `index.html`をダブルクリックします。
3. 「ゲーム開始」を押します。

## ルール
- 画面上部の「今回の目当て」に表示された商品を覚えます。
- 店員の手が商品に半額シールを貼ります。
- 目当ての商品にシールが貼られた場合だけ、その商品をクリックします。
- シールが貼られる前、違う商品、目当てではない商品を押すとゲームオーバーです。
- 反応が遅いと他のお客さんに取られた扱いになります。

## 難易度上昇
- 6連続以降: 目当てが2商品
- 15連続以降: 目当てが3商品
- 連続数に応じて店員の移動速度と判定時間が厳しくなる
- 4連続以降: フェイントが発生
- 連続数に応じて目当て以外へシールを貼る確率が上がる

## 編集しやすい場所
`script.js`上部の`PRODUCTS`で商品名と絵文字を変更できます。
`getDifficulty()`で難易度調整ができます。
